
# Jenkins CI/CD Demo

## Project Overview
This repository is used to learn and implement DevOps practices using Git, GitHub, Jenkins, Maven, and Java.

## Objectives
- Understand Git branching and version control.
- Practise Pull Requests and Code Reviews.
- Configure a Jenkins CI/CD pipeline.
- Automate Java application builds using Maven.
- Run automated tests.
- Understand build and deployment processes.

## Tools Used
- Java
- Maven
- Git
- GitHub
- Jenkins
